# CRISP-DM 專案設計文件

## 專案目標

使用 50 Startups 資料集建立可解釋、可重現的公司獲利預測流程，並比較不同線性迴歸方法在小型結構化資料上的泛化表現。

## 1. Business Understanding｜商業理解

### 商業問題

新創公司需要在研發、行政與行銷之間分配有限預算。專案希望回答：

- 哪些投入與公司獲利最相關？
- 不同投入組合可能對預測獲利造成什麼影響？
- 正則化或穩健迴歸是否比一般線性迴歸更適合此資料？

### 分析目標

- 建立公司獲利預測模型。
- 比較五種線性迴歸方法。
- 提供可解釋的係數、模型方程式與殘差診斷。
- 建立可供非技術使用者操作的互動式儀表板。

### 成功條件

- 主要指標：測試集 RMSE。
- 輔助指標：MAE、R²、殘差分布。
- 操作條件：同一資料切分、相同前處理、結果可重現。

## 2. Data Understanding｜資料理解

### 資料來源與規模

- 樣本數：50
- 原始特徵數：4
- 目標欄位：`Profit`
- 類別欄位：`State`
- 數值欄位：`R&D Spend`、`Administration`、`Marketing Spend`

### 資料品質

- 無遺漏值。
- 數值欄位使用相同貨幣尺度，但範圍不同。
- 州別共有三類，需要轉為模型可讀取的數值欄位。
- 樣本量小，評估結果容易受到資料切分影響。

### 初步假設

- 研發支出預期與獲利呈正向關係。
- 行銷支出可能提供額外預測能力。
- 行政支出與州別的貢獻可能較弱。

## 3. Data Preparation｜資料準備

### 變數角色

- `X`：除 `Profit` 外的所有欄位。
- `y`：`Profit`。

### 前處理

1. 類別欄位以 One-Hot Encoding 轉換。
2. 第一個州別作為基準類別，避免完全共線性。
3. 數值欄位若出現遺漏值，以中位數補值。
4. 模型輸入使用 StandardScaler 標準化。

### 資料切分

- 訓練集：80%，共 40 筆。
- 測試集：20%，共 10 筆。
- 隨機種子：42。

固定切分讓所有模型在相同資料下比較。

## 4. Modeling｜模型建立

### 模型清單

| 模型 | 目的 |
|---|---|
| Linear Regression | 建立無正則化基準模型 |
| Ridge | 以 L2 降低係數波動 |
| Lasso | 以 L1 壓縮係數並進行特徵選擇 |
| Elastic Net | 結合 L1 與 L2 |
| Huber | 降低離群值影響 |

### 參數選擇

- Ridge：以交叉驗證選擇 `alpha`。
- Lasso：以交叉驗證選擇 `alpha`。
- Elastic Net：以交叉驗證選擇 `alpha` 與 `l1_ratio`。
- Huber：使用 `epsilon=1.35` 與輕度正則化。

### 特徵數分析

對每個模型分別執行：

1. 將州別展開後得到 5 個候選特徵。
2. 對 `k=1` 至 `k=5` 枚舉特徵子集合。
3. 使用訓練集五折交叉驗證選出該 `k` 的最佳組合。
4. 使用保留測試集計算 RMSE 與 R²。

互動網站提供 `K=1～K=5` 五組按鈕。使用者選擇 K 後，會同步更新 RMSE、R²、調整後 R²、MAE、F-statistic、特徵子集合、模型方程式、係數、預測值與殘差。

演算法與 K 值採雙條件聯動：切換演算法時保留目前 K，跨模型 RMSE 圖與排行榜則依該 K 的測試結果重新排序。正則化模型的 F-statistic 僅作描述性參考，不視為傳統 OLS 的正式推論檢定。

此流程避免直接以測試集選擇特徵。

## 5. Evaluation｜模型評估

### 評估指標

- MAE：衡量平均絕對預測誤差。
- RMSE：提高大誤差的影響，作為模型排名主要依據。
- R²：衡量模型對獲利變異的解釋比例。
- Residual：檢查高估、低估與離群樣本。

### 實驗結論

Lasso 在本次固定測試集上取得最佳表現：

- MAE：6,419.67
- RMSE：7,967.65
- R²：0.9216

Lasso 將州別係數壓縮至接近零，顯示此資料中的主要預測訊號來自數值型支出特徵。

### 風險與限制

- 50 筆資料不足以代表所有新創公司。
- 單次訓練／測試切分可能造成評估波動。
- 線性模型無法描述複雜非線性關係。
- 資料缺少產業、成立年數、市場環境等重要資訊。

## 6. Deployment｜部署

### 產出

- Python 執行結果
- JSON 模型資料

- 靜態互動式網站

### 更新流程

1. 更新 `50_Startups.csv`。
2. 執行 `compare_models.py`。
3. 確認 JSON 與 PNG 產出。
4. 啟動靜態網站並檢查五模型切換。
5. 發布 `startup-profit-dashboard/dist`。
